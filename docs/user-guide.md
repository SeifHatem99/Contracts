# Same Day Home Solutions User Guide

## Overview
This application manages real estate deals, templates, generated contracts, contacts, properties, files, and communication records entirely offline in the browser.

## Core Workflow
1. Create or open a Deal.
2. Fill in the property, seller, buyer, and financial details once.
3. Select a contract template.
4. Review the final contract summary.
5. Generate the DOCX contract.
6. Export, duplicate, archive, or compare the document as needed.

## Keyboard Shortcuts
- `Ctrl/Cmd + K`: Open Search
- `Ctrl/Cmd + S`: Save draft
- `Ctrl/Cmd + Shift + D`: Open Diagnostics

## Best Practices
- Keep contacts and properties in their libraries so they can be reused.
- Review the Final Review screen before generating contracts.
- Check Diagnostics if anything seems off after import, restore, or export.
