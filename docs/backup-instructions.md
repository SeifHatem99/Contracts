# Backup Instructions

## Manual Backup
- Open Data or Sync.
- Choose `Manual Backup` or `Create Backup`.
- Download the backup file for safekeeping.

## Automatic Protection
- The app stores local data continuously.
- Template changes create new versions automatically.
- Generated records are preserved and never overwritten.

## Restore Workflow
1. Open the Backup History.
2. Select a saved backup.
3. Restore it after confirming the action.
4. Review the Dashboard and Diagnostics after the restore completes.
