# Maintenance Guide

## Routine Checks
- Review Diagnostics weekly.
- Verify backups are created before major template edits.
- Monitor audit history for unexpected changes.

## Data Hygiene
- Keep contacts and properties current.
- Archive obsolete documents instead of deleting them when possible.
- Remove only unused templates after confirming a backup exists.

## Performance Tips
- Keep the backup history under control.
- Prefer reusable contacts, properties, and clauses.
- Use Search instead of manually browsing large lists.
