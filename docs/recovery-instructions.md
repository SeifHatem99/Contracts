# Recovery Instructions

## If Data Looks Wrong
1. Open Diagnostics.
2. Review recent errors and backup status.
3. Restore the most recent valid backup if needed.

## If Import Fails
- Confirm the file was exported by this application.
- Check that the backup structure is complete.
- Use a known good backup file if the current one is corrupted.

## If a Template Is Corrupted
- Open Template Manager.
- Restore a previous version.
- Replace the master template only after validating the new content.
