# Setup Instructions

## Local Use
1. Open `index.html` in Google Chrome.
2. Allow the browser to store local data for the application.
3. Create your first Deal or use the seeded templates.

## Recommended Environment
- Google Chrome on desktop
- Local filesystem access enabled
- No backend or server required

## First Run Checklist
- Confirm the company name in Settings.
- Review the default title company.
- Verify the contract templates are present.
- Create a backup after first configuration.
